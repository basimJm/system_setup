## 1. Executive Summary
One package through which the __SYSTEM_NAME__ backend records business events (what happened, to whom, when) and links anonymous activity to known users, delivering them in batches to a replaceable destination without ever slowing down the request path.

## 2. Business Context
Product and operations decisions need server-side truth (bookings, payments, cancellations) next to client analytics. The destination (warehouse, vendor) may change; losing a few events under outage is acceptable, blocking a booking is not.

## 3. Goals
- G1 `track` / `linkIdentity` with one stable interface.
- G2 Batching and retries with explicit loss accounting.
- G3 Destination replaceable by configuration; dev without any vendor.

## 4. Scope
### 4.1 In Scope
Event and identity envelopes, validation, queueing, batching, timer flush, retries, drop counters, memory/fake/http sinks.
### 4.2 Out of Scope
Client-side tracking, dashboards, event taxonomy governance, consent management, sampling.

## 5. Business Requirements
| ID | Requirement | Acceptance |
|---|---|---|
| ANA-R1 | Tracking never throws for delivery problems | only `VALIDATION_FAILED` surfaces to the caller |
| ANA-R2 | Events carry a user or an anonymous id, a snake_case name and flat properties | validation |
| ANA-R3 | Anonymous history can be linked to a user | `linkIdentity` envelope |
| ANA-R4 | Delivery is batched and retried on transient failures | `batchSize`, `retry` |
| ANA-R5 | Lost events are counted, never silent | `dropped`, error logs |
| ANA-R6 | Production refuses in-memory sinks and plain-http collectors | `CONFIG_INVALID` |

## 6. Non-Functional Requirements
O(1) `track`; bounded queue and payloads; timers do not keep the process alive; ≥ 95 % coverage; ESM + CJS.

## 7. Success Metrics
`dropped` ≈ 0 in steady state; destination change without consumer code changes; `npm run verify` green.

## 8. Risks & Mitigations
| Risk | Mitigation |
|---|---|
| Collector outage | bounded queue, retries, drop counter as a metric |
| PII in properties | consumer policy; redacting logger for secret-looking keys |
| Unbounded memory under burst | `maxQueue` drops oldest |
