## 1. What it is
`__NPM_SCOPE__/__SDK_KIND__` — __SDK_DESCRIPTION__

## 2. The port
`__SDK_TITLE__Port.execute(request)` takes `{ operation, payload }` and returns `{ id, status: DONE | QUEUED }`. It rejects with `SdkError`; an error is `retryable` only when repeating the call is safe. `close()` is optional.

## 3. Usage
```ts
const client = create__SDK_TITLE__({ environment: 'dev', provider: 'fake' });
await client.execute({ operation: 'ping', payload: {} });
```
Prod: `provider: 'custom'` with `port: <the adapter of the chosen provider>`; fakes are refused.

## 4. Environment (keys only, see `.env.example`)
`__SDK_PREFIX___ENVIRONMENT` (dev | prod), `__SDK_PREFIX___PROVIDER` (fake | custom). The consumer maps them to `__SDK_TITLE__Options`.

## 5. Errors
Every code starts with `__SDK_PREFIX___`: the kernel codes plus `__SDK_PREFIX___OPERATION_FAILED` (an adapter failure that was not already typed).

## 6. Contract test
